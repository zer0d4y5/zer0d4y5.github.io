CVE-2026-114615 Authlib CWE-184 · CWE-347 · 7.4 High (CVSS 3.1) 2026-10-22

Off by one newline: how Authlib's JWT algorithm confusion came back

Authlib's fix for CVE-2024-37568 only checked whether a key started with -----BEGIN, while the PEM loader skips anything in front of it. One leading newline turned the issuer's public key back into an HS256 secret, so anyone holding it could forge tokens.

→ fixed in Authlib 1.9.0 · GHSA-7vr2-2fgp-9w7p
CVE-2026-105937 Apache Pulsar CWE-862 · 8.7 High (CVSS 4.0) 2026-10-21

Reading another tenant's messages through an Apache Pulsar shadow topic

A tenant admin could create a topic in their own namespace, point its reserved PULSAR.SHADOW_SOURCE property at a topic in another tenant, and consume that tenant's stored messages. The broker never checked the caller against the source topic.

→ fixed in Pulsar 4.0.14, 4.2.5 and 5.0.0
CVE-2026-112947 Vite CWE-22 · CWE-209 · 6.3 Medium (CVSS 4.0) 2026-10-20

Reading past Vite's server.fs boundary through a WebAssembly error

An internal query from Vite 8.2's Wasm support reached a plugin that read files without checking server.fs. The WebAssembly parse error then sent the first four bytes of any file on the host back to the requester.

→ fixed in Vite 8.2.4 and 8.3.3 · GHSA-vfpm-58rq-9qcg
CVE-2026-110779 CVE-2026-110780 Netatalk CWE-125 · CWE-476 · 4.3 / 5.3 Medium 2026-10-15

Two memory-safety bugs in Netatalk's Spotlight RPC

Netatalk's Spotlight decoder was well guarded. The handlers reading its output assumed every CNID array had a first element and that every element was a 64-bit integer, giving a NULL dereference and a heap over-read.

→ fixed in Netatalk 4.5.2 · advisories on netatalk.io
CVE-2026-96615 NGINX Gateway Fabric CWE-290 · 7.1 High (CVSS 4.0) 2026-10-14

Cross-namespace agent impersonation in NGINX Gateway Fabric

The control plane verified each nginx agent's ServiceAccount token, then took the Gateway it belonged to from a label the agent wrote itself. Any tenant could claim another Gateway and read its TLS private keys.

→ fixed in NGINX Gateway Fabric 2.8.0 · F5 advisory K000162610
CVE-2026-85184 @fastify/middie CWE-436 · 9.1 Critical 2026-09-04

When your router and your middleware read different URLs

Fastify's router resolves an absolute-form request target before it dispatches. middie, deciding whether your path-scoped middleware runs, matched the raw string, so the authentication middleware on the route never ran.

→ fixed in @fastify/middie 9.3.4
CVE-2026-41992 GNU gzip CWE-126 · 6.9 Medium 2026-08-30

The gzip patch that fixed the crash and left the bug

The first fix cleared gzip's poisoned Huffman arrays in the branch that crashed, not in the function that reads them, leaving the out-of-bounds read reachable a few lines below.

→ fix landed upstream in e7378c2d · credited in gzip THANKS and the CVE record
